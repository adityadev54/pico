# Pico palette

Pico uses warm neutral surfaces and red semantic accents. Pico’s held-point symbol remains distinct, and the home screen uses the selected companion character. Auth uses the Pico emblem and email/password only.

lib/theme/app_theme.dart is the app’s source of truth. Brand/action gradients use these existing roles. All device icon exports and the webpage use the same palette. Pico’s geometry and wordmark are unchanged.
