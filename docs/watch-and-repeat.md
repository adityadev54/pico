# Watch & repeat

Teach Pico a selected-file transformation once, then repeat it on fresh inputs. The same flow works for study notes, briefs, meeting summaries and other source-backed documents; it is not a general mouse/keyboard recorder.

## Teach on your computer

1. Give an existing workspace **write** access in the companion’s folder permissions.
2. Choose **Teach a routine…** in the companion menu, or **+ → Watch & repeat → Teach on my computer** on the phone.
3. Name the routine and select one to four source documents inside that workspace. Choose a separate Markdown example file.
4. Edit and save the example in TextEdit (Mac) or Notepad (Windows). Show the result you want, rather than just writing an instruction such as “make study notes.” Only changes to the selected example are observed.
5. Choose **Finish teaching…** and approve sending the selected contents and example to Muse. A successful response saves a local recipe.

## Repeat during normal work

Change the source notes, or choose replacement inputs. On the phone, open the routine’s inline card, review its inputs and run it. You can also ask naturally using the saved routine’s name. Pico reads the current files, asks Muse for the demonstrated transformation, validates quoted evidence, and saves a new Markdown result without replacing the original.

Use **Open latest result** on the computer to open the verified output. If a request fails, review the error and choose to retry; no model retry runs automatically. Changed inputs, revoked access and replayed run identifiers stop an unsafe or duplicate run.

## Boundaries

Inputs: UTF-8 text, Markdown, CSV, DOCX or text-based PDF (up to 20 pages). Select at most four inputs and 6,000 characters total; the example is limited to 2,000 characters. Scanned documents need OCR elsewhere. Output quotations are matched against selected sources; interpretation can still be wrong and should be reviewed.

Both desktop companions use the same teaching engine. Windows bundles its runtime; installing Python is unnecessary for the downloaded app. A phone-only session cannot read desktop files while the computer is disconnected.
