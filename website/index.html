Open Pico ↗
iPhone instructions +
  1. Open Pico in Safari and tap Share.
  2. Choose Add to Home Screen. Enable Open as Web App if shown, then tap Add.
  3. Open Pico from its Home Screen icon and sign up.

Installing Pico +

On macOS, open the disk image and drag Pico into Applications. On Windows, run Pico-Setup.exe to install for your account.

In Pico, enter the six-digit connection code from your phone.
